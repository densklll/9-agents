# Папка ТЗ — исходные технические задания

Сюда ты кладёшь оригинальные ТЗ перед стартом работы.

## Как использовать

1. Создай файл с понятным именем:
   - По дате: `2026-04-02-marketplace.md`
   - По теме: `payment-integration.md`, `admin-panel.md`

2. Вставь туда своё ТЗ в любом формате — текст, список, описание, скопированное из чата

3. Скажи Диме: "Есть ТЗ в папке tz/" — он прочитает, проведёт интервью и разложит всё по фазам

## Что Дима сделает с ТЗ

1. Прочитает файл полностью
2. Задаст уточняющие вопросы по серым зонам
3. Заполнит `REQUIREMENTS.md` — v1 / v2 / вне скопа
4. Заполнит `ROADMAP.md` — фазы с зависимостями
5. Покажет план и дождётся твоего подтверждения

## Важно

- Файлы в этой папке **не редактируются агентами** — это первоисточник
- Можно хранить несколько ТЗ — каждое в отдельном файле
- Если ТЗ изменилось — добавь новый файл, старый не удаляй
