# Threads — персистентные нити контекста

> Создаёт и обновляет **только Дима** (team-lead). Остальные агенты — только читают.
> Завершённые threads переносятся в `archive/threads/`.

## Когда создавать thread

- Задача порождает знания, которые нужны за её пределами (через 3–5 задач)
- Расследование не закончено и переносится в следующую сессию
- Тема затрагивается в нескольких несвязанных задачах (например: "архитектура авторизации", "проблемы с деплоем")

## Когда закрывать thread

- Тема полностью исчерпана или решена
- Знания зафиксированы в PROJECT_CONTEXT.md и больше не нужны как отдельная нить
- Дима помечает статус "закрыт" и переносит файл в `archive/threads/`

## Формат файла

Имя файла: `{slug}.md` — например `payment-integration.md`, `auth-architecture.md`

```markdown
# [Название темы]

**Статус:** открыт / закрыт
**Создан:** [дата]
**Связанные задачи:** #[номер], #[номер]

## Факты
[Что точно известно]

## Открытые вопросы
[Что ещё не выяснено]

## История
[Краткая хронология что происходило по этой теме]
```
