# Решения по проекту

> Записывает **только Дима** (team-lead) по результатам работы Серёги и команды. Остальные — только читают.
> Здесь фиксируется **почему** выбрали подход А, а не Б. Бесценно через месяц.

---

## Формат записи

Каждое решение — по этому шаблону:

**#[номер] — [Тема решения]**
- **Задача:** какую проблему решали
- **Выбрали:** подход и его суть в 1–2 предложениях
- **Почему:** обоснование выбора
- **Отвергли:** альтернативы и почему не подошли
- **Дата:** дата решения
